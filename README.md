One funny single-line excuse a developer gives when code breaks in production, for make.fun's "Make the AI Judge Laugh: Developer Excuses" bounty ($3 in USDC, top 10 share the prize). It turns the most worn developer excuse of all time — "it works on my machine" — by revealing why that machine is special: it is the only one that ever read the README.

> It worked on my machine — because my machine is the only one that ever read the README.

The line is 87 characters, one line, inside the 1–200 character gate.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the excuse to `/output/entry.txt`. No network, no randomness, no clock, so two runs write identical bytes.
